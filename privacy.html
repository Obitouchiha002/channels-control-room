Privacy policy

Channels Autopilot is used only by its owner for his own YouTube channels and Instagram account.

What the app accesses

With the owner's consent it uses the YouTube Data API and YouTube Analytics API to upload and schedule the owner's own videos, set thumbnails, captions and playlists, post comments on the owner's own videos, and read view and subscriber statistics of the owner's channels.

What is stored

OAuth tokens and channel statistics are stored only on the owner's own computer and in his private, encrypted GitHub repository secrets. No data is sold, shared with third parties or used for advertising.

Google user data

The app's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. YouTube API Services are used under the YouTube Terms of Service and Google Privacy Policy.

Revoking access

Access can be removed at any time at myaccount.google.com/permissions.
